用 SVG 画像素画,然后把它变成组件

字符画稿 + 调色板映射,一次定义、随意换色。

#svg #像素 #前端

目录

  • 渲染器
  • 为什么用 SVG 而不是图片
  • 限制

本站的吉祥物是用字符画画的。每个角色就是一堆字符串,每个字符代表一个颜色:

'..111111111111..',  // 毛色
'..1.44....44.1..',  // 眼睛
'..1.222.4.222.1..', // 口吻

渲染器

把字符网格翻译成 SVG 的 <rect>,一行一个像素格:

for (let y = 0; y < art.height; y++) {
  for (let x = 0; x < art.rows[y].length; x++) {
    const fill = palette[art.rows[y][x]]
    if (!fill) continue
    cells += `<rect x="${x * pixel}" y="${y * pixel}" ... />`
  }
}

为什么用 SVG 而不是图片

  1. 换色自由:四个主题的吉祥物就是四套调色板,零额外资源
  2. 无限放大:shape-rendering="crispEdges" 保持像素锯齿,越放大越有味道
  3. 尺寸小:一个吉祥物不到 1KB

限制

  • 只能做”大头贴”级别的造型,复杂插画还是得靠真像素画师
  • 未来替换正式插画时,组件接口(role + theme)不用改,换数据源就行

这大概就是”先用轮子占位,以后换引擎”的典型写法。

# 文章管理重写设计规格(文档库 · 经典左右分栏)

> 来源:`frontend-design-ui-ux` skill 流程。用户确认:文件树/编辑器/布局均异常,框架变动下直接重写;布局采用经典左右分栏(Obsidian/Joplin 风格)。

---

## 1. 用户与上下文

- **用户**:站长。工作流 = 外部软件写作(产生文件树文档,多为无后缀 txt + 少量 md)→ 导入/管理 → 编辑 → 保存。
- **产品目标**:文档库像 Obsidian/Joplin:左文件树、右编辑区,稳定、流畅、可长期承载文档。
- **历史问题(重写原因)**:
  - react-arborist 与当前样式体系冲突(树行高/缩进/图标错位,展开状态不稳定)
  - TOAST UI 在 React 19 下需纯 JS 手动挂载,高度与布局难控
  - 文章管理页整合方式生硬(Tab 嵌套,布局比例失调)
- **约束**:React 19、shadcn/Radix 体系、TOAST UI Editor 3.2.2(纯 JS 实例)、现有 admin API(docs CRUD 已就绪)。
- **可访问性**:键盘可达(树方向键/回车)、语义标签、焦点可见。

## 2. 流程与状态

**主旅程**:文章管理页 → 左侧文件树浏览(展开/折叠/选中)→ 打开文件 → 编辑(WYSIWYG/源码)→ 保存(按钮/Ctrl+S)→ 树刷新。

**状态模型**:

| 状态 | 表现 |
|------|------|
| 加载中 | 骨架屏(树区 + 编辑区) |
| 空文档库 | 树区空态引导(新建按钮),编辑区占位 |
| 选中目录 | 树高亮,编辑区显示目录占位(无编辑) |
| 打开文件 | 编辑器加载内容;标题=文件名;树节点高亮 |
| 编辑中 | 「未保存」标记;保存按钮可点 |
| 保存中 | 按钮 loading,完成后轻提示 + 树静默刷新 |
| 错误 | toast(读取/写入/重命名/删除失败) |
| 拖拽移动 | 树节点拖动中高亮,落点目录高亮;完成后刷新 |

## 3. 组件规格

### 3.1 Layout:文章管理主布局

- 顶部工具条(通栏):标题「文章管理」+ 搜索框(过滤树节点,可选)+ 视图切换(文档库 / 文章列表)。
- 主体:`flex` 行:**DocTree(280px,可折叠至 0)** + **DocEditor(弹性)**。折叠按钮在工具条或侧栏头。
- 文章列表视图:保留现有列表(筛选/新建文章/状态徽章),作为独立视图切换,不再嵌套 Tab。

### 3.2 DocTree(文件树面板)

- **目的**:文件树浏览与文件操作入口。
- **结构**:
  - 面板头:图标按钮(折叠面板)+ 标题「文档库」+ 新建文件/新建文件夹按钮。
  - 树区:递归行(目录可展开/折叠,文件可选中),缩进层级,行高 30px。
  - 行内容:类型图标(目录开/合、txt、md)+ 名称 + 悬停操作(重命名 ✎ / 删除 🗑)。
- **交互规则**:
  - 点击目录行:切换展开(不选中编辑)。
  - 点击文件行:选中 + 打开编辑(重复点击已选中文件:无操作)。
  - 双击目录:切换展开。
  - 新建文件/文件夹:面板头按钮 → 行内输入框(自动聚焦,Enter 确认 / Esc 取消)。
  - 重命名:行悬停 ✎ → 行内输入框 → Enter 确认。
  - 删除:确认弹窗(目录提示级联删除)。
  - 拖拽:目录/文件可拖入目录(含根),落点高亮;同目录内调整顺序(可选,暂仅支持移入目录)。
  - 展开状态:会话内记忆。
- **状态**:默认(可展开)/ 选中(primary 高亮)/ 悬停(操作按钮浮现)/ 编辑中(行内输入)/ 拖拽中。
- **无障碍**:`role="tree"`/`treeitem`,方向键上下移动、←→ 折叠展开、Enter 打开;名称可聚焦。
- **响应式**:<1024px 树面板默认折叠(按钮展开)。
- **性能**:树节点 <2000 时全量渲染(现有规模足够);大库再考虑虚拟化。

### 3.3 DocEditor(编辑面板)

- **目的**:文档编辑(WYSIWYG 为主)。
- **结构**:
  - 编辑头:文件名(截断)+ 类型徽章(txt/md)+ 「未保存」标记 + 操作(重命名/删除)+ 保存按钮。
  - 编辑器主体:TOAST UI 实例(纯 JS 挂载),高度 = 面板剩余高度(100% flex),WYSIWYG 默认 + 源码切换。
  - 目录占位:选中目录时显示目录名 + 「新建文件于此」快捷按钮。
- **交互规则**:
  - 打开文件:切换文件时保存当前脏状态提示(确认丢弃/自动保存可选,默认:未保存切换时确认弹窗)。
  - 保存:Ctrl/Cmd+S 与按钮等效;成功后清「未保存」。
  - 只读感知:空文件可编辑;txt 与 md 同编辑器(markdown 语义,存回原扩展名)。
- **状态**:空(未选择)/ 目录占位 / 文件编辑 / 脏 / 保存中 / 保存失败。
- **无障碍**:编辑器为标准 contenteditable;保存按钮可聚焦。
- **响应式**:<768px 编辑器在上、树变抽屉。

### 3.4 复用与保留

- 文章列表视图:沿用现有 PostsPage 列表逻辑(筛选/新建文章对话框/删除确认)。
- 后端:`/admin/api/docs` CRUD 完全复用,不改。
- TOAST UI:维持纯 JS 实例化(React 19 兼容),封装为 `useToastEditor` hook(创建/销毁/设值/取值)。

## 4. 设计令牌

- **面板**:树 280px;编辑器 min-width 0;分隔 12px;面板圆角/边框沿用 `Card`。
- **树行**:高 30px,缩进 14px/级,圆角 6px;选中 `bg-primary/10 + text-primary`;悬停 `bg-accent`。
- **图标**:16px(lucide:Folder/FolderOpen/FileText/FilePlus/FolderPlus/Pencil/Trash2/Save/Search/ChevronRight)。
- **反馈**:保存成功 sonner;错误 sonner;「未保存」琥珀小徽章。
- **动效**:行高亮/展开 0.15s ease;面板折叠 0.2s。
- **层级**:编辑头 z-10;树面板独立滚动;编辑器独立滚动。

## 5. 工程交接

- **目标**:客户端 React(纯 SPA 控制台),`src/components/admin/pages/posts.tsx` 重构 + `docs-manager.tsx` 重写。
- **文件**:
  - `posts.tsx`:主布局(工具条 + 视图切换 + 左右分栏容器)
  - `docs-manager.tsx` → 拆分:`DocTree.tsx`、`DocEditor.tsx`、`useToastEditor.ts`
  - 样式:继续 Tailwind + shadcn 令牌,不引入新 UI 库
- **不接受**:树组件换库(自绘递归树,行逻辑完全可控)、嵌套 Tab、固定像素高度。

**验收标准**:
- [ ] 左右分栏稳定渲染,树可折叠/展开,比例自然
- [ ] 树:展开/折叠/选中/新建/重命名/删除/拖拽移动全部可用,状态无错位
- [ ] 编辑器:高度随面板自适应,打开/切换/保存/Ctrl+S 正常,脏状态提示
- [ ] 文章列表视图保留原有功能
- [ ] 空库/加载/错误状态齐全
- [ ] 键盘可操作树与保存
- [ ] 零 JS 错误;双构建 + 测试通过
